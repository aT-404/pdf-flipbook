# PDF Flipbook

Turn any PDF into a book you can flip.

- You see **two pages at a time**, like an open book (you can switch to one page any time).
- You turn the pages by **swiping** (or dragging with the mouse), with a real page-turn animation.
- You hear a soft **page-turn sound** (you can switch it off).
- You can **save your book as one file** and send it to anyone. They open it with a double-click, even without internet.
- It works on Windows and Mac.
- **Your PDF never leaves your computer.** Nothing is uploaded to the internet.

---

## The 4 steps (short version)

1. Install **Node.js** (one time only).
2. **Unzip** this folder.
3. **Double-click** the START-HERE file for your computer.
4. Click the big box in your browser and choose your PDF.

The long version with pictures-in-words is below. Take your time. You can do this.

## Before you start

You need:

- A Windows or Mac computer
- An internet connection (only for the first set-up, about 10 minutes)
- Google Chrome, Microsoft Edge, Firefox or Safari

---

## Step 1. Install Node.js (one time only)

Node.js is a free helper program. The app needs it to run. You only do this step once.

1. Open your browser and go to **https://nodejs.org**
2. Click the big green button that says **LTS**. A file will download.
3. Open the downloaded file.
4. Click **Next** (Windows) or **Continue** (Mac) again and again, then click **Install**.
   Do not change anything. The normal choices are correct.
5. When it says it is finished, click **Finish** or **Close**.

> If you already have Node.js on your computer, skip this step.

---

## Step 2. Unzip the folder

The folder came as a ZIP file. You must open (unzip) it first.

**Windows**

1. Find the ZIP file (usually in your **Downloads** folder).
2. Right-click it and choose **Extract All...**
3. Click **Extract**.
4. A new normal folder opens. Use this new folder. Do **not** use the ZIP file.

**Mac**

1. Double-click the ZIP file. A new folder appears next to it.

Tip: move the new folder to your **Desktop** or **Documents** so it is easy to find later.

## Step 3. Start the app

### On Windows

1. Open the folder.
2. Double-click **START-HERE-Windows**.
3. If a blue window says **"Windows protected your PC"**:
   click **More info**, then click **Run anyway**. (This message is normal for files you download.)
4. A black window opens with lots of moving text. **This is normal.**
   - The **first time**, it needs **2 to 5 minutes**. Please wait. Do not close it.
   - Next times, it opens in a few seconds.
5. When you see **"PDF Flipbook is running!"**, your browser opens by itself.

### On Mac

1. Open the folder.
2. Double-click **START-HERE-Mac.command**.
3. If a message says the file **"cannot be opened"** or is from an **"unidentified developer"**:
   - Right-click (or hold the Control key and click) the file.
   - Choose **Open**.
   - Click **Open** again.
4. A window opens with lots of moving text. **This is normal.**
   - The **first time**, it needs **2 to 5 minutes**. Please wait. Do not close it.
   - Next times, it opens in a few seconds.
5. When you see **"PDF Flipbook is running!"**, your browser opens by itself.

### If your browser did not open by itself

Look at the black window. It shows an address like this:

```
http://localhost:3000
```

Open your browser, click the address bar at the top, type that address, and press Enter.

> **Keep the black window open** while you read. If you close it, the app stops.

## Step 4. Read your PDF

1. In the browser, click the big box that says **"Click here to choose a PDF"**.
   (You can also drag a PDF file and drop it on the box.)
2. Wait a moment. Big PDFs take a few seconds.
3. Your book opens. Enjoy!

### How to use the book

| What you want | What to do |
| --- | --- |
| **Turn the page** | **Swipe** with your finger, or **drag** the page with your mouse. You can also click a page corner. |
| **Turn the page with the keyboard** | Press the **Right arrow** or **Left arrow** key. |
| **Go to the first or last page** | Press the **Home** or **End** key. |
| **Go to a page number** | Click the text that says **Page 4–5 / 20** at the bottom, type a number, and press Enter. |
| **See all pages as small pictures** | Click the **four squares** button at the bottom left. Click any page to go there. |
| **Make the book bigger or smaller** | Click the **+** and **−** buttons at the bottom. |
| **Switch the page-turn sound on or off** | Click the **open book** button at the bottom and click **Page-turn sound**. A tick means the sound is on. |
| **Save the book as one file to send to others** | Click **Download as flipbook** at the top right. See "Send your book to someone else" below. |
| **Show 1 page or 2 pages** | Click the **open book** button at the bottom. Choose **2 pages (like a book)** or **1 page**. It starts with 2 pages. |
| **Fix pictures that cross two pages** | Click the **open book** button and click **First page alone** to turn it off (or on). Try this if a picture that goes across two pages does not line up. |
| **Full screen** | Click the **arrows** button at the bottom right. Press **Esc** to leave. |
| **Open a different PDF** | Click **Choose another PDF** at the top left. |

**On a phone:** it also shows 2 pages. Turn your phone **sideways** to make the pages bigger, or use the **+** button to zoom in.

The buttons at the bottom hide by themselves after a few seconds so you can read.
Move your mouse or touch the screen and they come back.

## Send your book to someone else

You can turn your book into **one single file** and send it to anyone (by email, WhatsApp, a USB stick, and so on).
The other person does **not** need this app, **not** need to install anything and **not** need internet.

**How to make the file**

1. Open your PDF in the app.
2. Choose how you want the book to look first (1 page or 2 pages, sound on or off).
   The file will start with the same choices. The other person can still change them.
3. Click **Download as flipbook** at the top right. A progress bar shows.
4. A file called something like `My notes (flipbook).html` is saved in your **Downloads** folder.

**How the other person opens it**

1. Double-click the file. It opens in their browser (Chrome, Edge, Firefox or Safari).
2. That is all. They can swipe, zoom, see all pages, and use the same buttons.
   They can also click **Save PDF** at the top to get the original PDF back.

**Good to know**

- The file is a little bigger than your PDF (about 3 MB more, plus a third more of the PDF itself).
  A 5 MB PDF becomes a file of about 10 MB.
- Very big PDFs (hundreds of MB) may not work. You will see a message if that happens.
- If the PDF has a password, the other person must type the password when they open the file.
- **On a phone:** save the file first, then open it with the phone's browser (for example from the Files app).
  Some email apps only show a quick preview and do not run it. A computer is easiest.

## Something went wrong? Try this

**"Node.js is not installed on this computer yet."**
Do Step 1 again. When it is finished, double-click the START-HERE file again.

**The black window shows a message and closes, or says "This file must stay inside the folder".**
You probably opened the file from inside the ZIP. Go back to **Step 2** and unzip (Extract All) first.

**The browser says "This site can't be reached".**
The black window was closed. Double-click the START-HERE file again and keep the black window open.

**The first-time set-up fails or shows red error text.**
- Check that you are connected to the internet, then try again.
- If you are on a hospital, college or office network, it may block the download. Try your phone's hotspot or your home Wi-Fi.
- If it still fails, take a screenshot of the black window and send it to the person who shared this with you.

**The address is not 3000 (for example 3001).**
That is fine. Another program was using 3000. Use the address shown in the black window.

**My PDF does not open.**
- The file may be damaged. Try opening it in another program first.
- If the PDF has a password, a small box asks for it. Type the password and click OK.

**The flipbook file I received does not open, or shows plain text.**
Right-click the file, choose **Open with**, and pick Chrome, Edge, Firefox or Safari. If it still fails, save it to the computer first (do not open it from inside an email or a ZIP file).

**I cannot hear the page-turn sound.**
Check that your computer is not muted. Click the **open book** button and make sure **Page-turn sound** has a tick. Your browser only allows sound after you click or touch the page once.

**A page looks empty for a moment when I turn pages very fast.**
This is normal. The app draws pages as you read. Big PDFs need a moment.

**On Mac, double-clicking does nothing.**
Open the app called **Terminal**. Type `cd ` (the letters c, d and a space), drag the folder into the Terminal window, and press Enter. Then type `npm install` and press Enter. When it finishes, type `npm start` and press Enter.

## Common questions

**Is my PDF uploaded to the internet?**
No. The PDF is opened inside your own browser. It never leaves your computer.

**Does it work without internet?**
Yes, after the first set-up is finished.

**Does it change my PDF file?**
No. Your file is never changed.

**Is it free?**
Yes.

**Can I use it on my phone?**
Not with these steps. These steps are for a computer. Ask the person who shared this with you if they can give you a website link. A website link works on phones too (see `SHARE-AS-WEBSITE.md`).

## For developers

- Built with Next.js, React, Tailwind CSS, [PDF.js](https://mozilla.github.io/pdf.js/) (reads the PDF) and [StPageFlip](https://github.com/Nodlik/StPageFlip) (page-turn animation).
- Needs Node.js 20.9 or newer.
- Commands:
  - `npm install` : install everything (also copies the PDF.js support files to `public/pdfjs`)
  - `npm start` : build if needed, then serve the app on http://localhost:3000
  - `npm run dev` : development mode with live reload
  - `npm run build` : create the `out` folder (a plain static website)
  - `npm run lint` : check the code
- "Download as flipbook" builds one self-contained HTML file in the browser (`src/lib/export/build-flipbook.ts`). It stores the PDF (base64), PDF.js, the page-turn library and a small plain-JavaScript viewer (`public/export/viewer.js` and `viewer.css`) in that file. If you change the in-app viewer, keep `public/export/viewer.js` in sync.
- The page-turn sound is made with the Web Audio API (`src/lib/flip-sound.ts`), so no sound file is needed.
- The app is fully static. There is no server code, database or login.
- How the flipbook works: `src/components/flipbook/FlipbookViewer.tsx`.
  The book and its pages are created with plain DOM code on purpose, because StPageFlip moves and deletes the page elements it controls and React must not own them.
